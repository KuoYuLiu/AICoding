# AICoding

給程式設計初學者的 AI 輔助學習平台。AI 助理以蘇格拉底式提問引導學生解題、不直接給答案；AI 評分員依「題目理解、找尋語法、組合邏輯、語法理解、學習反饋」五個面向評量學生的思考過程，老師確認後才公佈。

目前狀態：規劃完成，準備開始階段 0（單題驗證原型）。
